# 死碎片：分布与机制（Soft A1）

> 数据：`backup/soft-a1/frag_dead.log` · 探针 `soft_a1 … inv=1` 的 `FRAG *` 行  
> 与 `ALIVE_DEAD.md` 配套：那边是页类存货，这里是 **MIX 页内死记录怎么铺开、从哪来、合并前后怎么变**。

---

## 1. 机制（代码路径 → 碎片形态）

```
put 覆盖键
  → flush_mem 写出新 L0 run（新页）
  → probe_prev 找到旧 winner
  → owner->live_bytes / Seg.live / Cell.dead 记账   (fcs.h ~5823–5837)
  → 旧 PK_DATA 字节不动
```

| 机制 | 何时 | 页内形态 | 回收出口 |
|------|------|----------|----------|
| **点覆盖**（本负载主因） | Soft A1 `upd` 随机键 | 死记录**打散**在页内（盐胡椒） | 整 run 退休 / 层合并重写 / TRIM 前缀 |
| **范围墓碑** | `del_range` | 键序上**连续死段**（本探针未开） | 同左 |
| **P2b TRIM** | 分片归并 | 前缀页进 `pending_free_`；page0 **锚**；裁边界页可能 MIX | 前缀整页释放，不是抠死记录 |
| **层合并** | L2→L3 | 活键重写到新 run；源块整段 → **PEND**（不是变 DATA_DEAD） | SB 后进 `free_` |

**没有**「把页内死记录就地擦成洞」的路径；页要么整页属 run，要么进所有权队列。

## 2. 时间线：死碎片密度怎么走

| 时刻 | dead_frac | MIX 密度直方图（页） | 页内三分位 | 含义 |
|------|-----------|----------------------|------------|------|
| 插入末 | ~0.05 | 几乎全 `<10%` | ~33/33/34 | 偶发覆盖，稀疏盐粒 |
| **upd #515（合前 L2 最脏）** | **0.246** | `<10%`:51 · `10-25`:466 · **`25-50`:1495** | 33/33/34 | 死集中在 **L2**；页仍全是 MIX，无全死页 |
| **峰 #569（L2→L3 刚合并）** | **0.030** | **`<10%`:1082** · `10-25`:72 · `≥25`:0 | 30/33/37 | 脏 L2 已变 **PEND=987**；新 L3 几乎干净 |
| END | 0.080 | 多为 `<10%`，少量 `10-25` | 33/33/34 | 新覆盖又开始撒盐 |

`avg_max_dead_streak`：合前 ~3.3，峰时 ~1.2 —— **几乎形不成长死段**（随机键覆盖特征）。

## 3. 空间分布（峰 #569）

**按层**

| 层 | dead_frac | mix_pages / np |
|----|-----------|----------------|
| L0 | 0.032 | 103/120 |
| L1 | 0.076 | 108/142 |
| L2 | （已并掉） | — |
| L3 | 0.025 | 943/1496 |

**按页内位置**：三分位始终接近 **1:1:1** ⇒ 拒绝「TRIM 前缀型 / 有序键尾部堆积」假说；坐实 **均匀随机点覆盖**。

**按页密度**：峰时 **dense MIX（≥25% dead）= 0**；合前曾有 1495 页 dense，但那些页在峰时刻已不在 DATA_*，而在 **PEND**。

## 4. 和峰值的关系（机制闭合）

```
合前：L2 页内死~25%（MIX dense）但整页仍占 run 块
  ↓ level merge
峰时：源 L2 → PEND（987 页）+ 新 L3 活页（死碎片稀）
  ↓ 峰 KPI
peak_tail ↑ 主要来自「源未 promote + 产物长尾」，不是「页内死字节胀破」
  ↓ SB / promote
末态：PEND→FREE，tail 回落；MIX 再次被新覆盖缓慢弄脏
```

因此：

1. **死碎片分布** = 记录级、页内均匀稀疏（峰）/ 中等密度（合前 L2）。  
2. **峰不靠攒全死页**；合前脏 L2 的回收走的是 **整 run→PEND**，不是 P2c 挖洞。  
3. 若只在峰时刻看 `DATA_DEAD=0` + `dead_frac=3%` 会误判「没有死」——合前 L2 曾有 25% 记录级死，只是形态一直是 MIX。

---

## 5. 对刀口的含义

| 刀 | 对死碎片 | 对 Soft A1 峰 |
|----|----------|----------------|
| P2c 页内挖洞 | 合前 L2 dense MIX 或有薄利；峰时 sparse ⇒ 无利 | **不对峰主因** |
| 加速 PEND→free / 养洞接产物 | 不碰页内死 | **对准峰** |
| 更早合并脏 L2 | 缩短 dense MIX 存活时间 | 可能降合前占用；时机旋钮曾否定，需新消融 |
