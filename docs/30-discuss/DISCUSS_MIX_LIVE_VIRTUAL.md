## 0. 场景钉死（勿治错病）

| 现象 | Soft A1 实测 | 治峰？ |
|------|----------------|--------|
| 页内盐胡椒死记录（MIX sparse） | 峰时 dead≈3%，三分位均，streak~1 | **否**（字节太少） |
| 合前 L2 MIX dense（25–50% 死/页） | #515；合并后整块变 **PEND** | 间接：已有整 run 回收 |
| 峰 = PEND + 养洞长尾 | PEND≈29%·tail | **主战场不在 MIX** |

本探讨仍有价值：MIX 是**稳态空间与读放大**的长期税（END dead_frac 回升到 ~8%）；且「无损性能」下若能薄利回收 dense MIX，可降低合前占用、缩短 PEND 体量。  
**明确不追求**：用页内抠洞单独打掉 A1 1.86× 峰（证据已否）。

**无损性能操作定义（门禁）**

- Soft peers：insert/update/get/range us/op 相对现 Soft **不劣于噪声**（或标 KPI 交换并拍板）。  
- 热 get：仍通常 **1 数据页**（bloom/sp 命中路径不加一次间接读）。  
- 默认路径零新子系统；任何刀可 `set_*`(0) 消融。

## 1. 思路族 → FCS 映射

### A. 活链（live chain / forwarding）

**想法**：死副本不搬，只挂「此键最新在 rid'/off」；旧页可整页丢弃当链可证明页内无 live。

| 变体 | 要点 | 性能风险 | 与现状 |
|------|------|----------|--------|
| A1 键级转发 | 旧记录改成指针 | get 最坏 +1 I/O；crash 一致性难 | **拒**：打穿「1 页读」 |
| A2 页级 live bitmap（RAM） | 不改盘；合并/退休参考 | 挂载重建成本；异步写易漂移 | 仅作 maint 启发，不入热读 |
| A3 「逻辑活链 = 已有 newer_has」 | 不存链，探测即链 | 已付 bloom 成本 | **已是**；勿再加持久链 |

**结论**：持久键级活链与「无损读」冲突。可用的只有 **已有版本序 + bloom**；或 **纯内存页脏度启发**（见 B），不写盘。

---

### B. 动态（density-triggered rewrite）

**想法**：MIX 不立刻动；当页/run 死密度过阈再重写活集（局部 compact），避免全局层合并那么重。

| 变体 | 要点 | 性能风险 | 证据贴合 |
|------|------|----------|----------|
| B1 run 级 dirty 提前并 | 降低 cliff / dirty% | EVAL17 **已否定**默认 | 勿回潮默认 |
| B2 **机会性单 run 重写** | maint 空闲 + `dead_frac≥θ` + 洞够装活集 ⇒ 写一条小 run，源 DEL | 写放大；抢洞抬峰 | θ 要高；**默认关**；A/B 峰+peers |
| B3 只扫 dense MIX 页重写 | 比整 run 细 | 需页级账或重扫；半页共享难 | Soft A1 合前 dense 在整 L2 run 上均匀 ⇒ 近似 B2 |
| B4 动态 θ | 近满抬 θ 敏感度 | 与已消融 `space_accel` 同类 | 仅实验旋钮 |

**无损贴法**：B2 挂 **Soft maint 空闲且非提交热路径**；失败/洞不够则跳过；消融=`set_mix_rewrite_pct(0)`。  
**预期**：降合前 L2 占用与随后 PEND 体积；**不保证**降 `peak_tail`（产物仍可能长尾）。

---

### C. 虚拟化（sparse / extent map / 逻辑地址）

**想法**：run 的「身份」与「物理页集合」解耦；owned = 活 extent 并集；死整页从 map 摘掉进 `free_`（P2c）。

| 变体 | 要点 | 性能风险 | 现状 |
|------|------|----------|------|
| C1 **P2c `M_RUN_HOLE`** | 格式级洞；预读截断 | 预读踩洞（坑 67）；搬家/hw2 复杂度 | op 已预留；设计写明**峰值无关**为主收益=压实后死页 |
| C2 逻辑页号 → 物理 | 完整虚拟层 | 热路径翻译；密度差 | **过重**，违反密度纪律 |
| C3 GGUF 式冷热层 | 热 run 占好洞，冷允许碎 | 策略面大 | 已用护洞近似热；勿第三套整理哲学 |
| C4 **段视图虚拟化**（已有） | Cell 只引用页区间+键域 | — | **已是**；死记录仍在物理页 |

**结论**：真要「整页已无 live 再还洞」，唯一贴 FCS 且已设计的是 **C1 P2c**，且触发应是 **整页 0 live**（`DATA_DEAD`），不是盐胡椒 MIX。Soft A1 峰 **DATA_DEAD=0** ⇒ P2c 在峰时刻无可挖整页；合前 L2 也是 dense MIX 而非全死页 ⇒ **P2c 仍吃不下盐胡椒**，除非先重写把死挤成整页（回到 B）。

## 2. 组合拳（推荐思考顺序，非实施令）

```
① 峰 / 养洞（已归因）     → 分配器接产物、PEND 尽快可复用   【空间峰主线】
② 动态 B2（可选薄刀）     → dense run 空闲时局部重写        【MIX 税 / 合前占用】
③ 虚拟 C1 P2c（条件）     → 仅当出现稳定 DATA_DEAD 整页     【压实/退休后的真洞】
④ 活链 A                 → 不采用持久转发；保持 newer_has   【读路径不动】
```

**性能守恒技巧**

1. **读路径零改**：get/select 仍段游标；洞/重写只动 owned 与 maint。  
2. **写热路径零改**：flush 仍 append-only；不在 put 上挂抠洞。  
3. **异步消化**：mode1/3 预算内；背压时宁可不做 B2。  
4. **消融默认关**：升 Soft 默认必须 A1+A2+A3 同向且 peers 不伤。

## 4. 明确不做（本探讨）

- 热路径键级活链 / 每 get 追转发。  
- 默默重开 cliff/dirty 默认（EVAL17 已否）。  
- 为 MIX 再堆第三套与 Soft 并行的「整理哲学」。  
- 宣称虚拟化已解决 1.86× 峰（未证且证据指向 PEND/养洞）。

---

## 5. 一句话

**混页的本质是「追加写 + 版本赢家」的必然盐粒；无损性能下只能 (1) 忽略稀疏 MIX，(2) 空闲时把 dense MIX 整 run 重写成新活链，(3) 仅对真正全死页做稀疏虚拟洞——活链探测已有，持久转发与全虚拟地址层不划算。峰仍优先养洞/PEND，不是抠碎片。**
