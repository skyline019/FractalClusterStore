\label{app:repro}

均在 \texttt{embdb/x} 下、WSL 环境：

\begin{lstlisting}[language=bash,caption={回归与关键探针}]
make ci-smoke                 # 与 CI 烟雾门对齐
make -j2 -s test              # 全量较久
make asan                     # ASan/UBSan + TSan 子集
make -j2 -s build/g18 && ./build/g18
# layout 峰值（需先编 probe）
g++ -std=c++17 -O2 -pthread -Iinclude \
  bench/probe/layout.cpp -o build/layout
./build/layout 200000 500 32 1 1 0 0 0 0 8
# Soft Post peers（现行产品）
bash scripts/peers_post_ab.sh
# 或：make peers-post
# 历史基线：backup/peers-r17/ · backup/peers-soft/
\end{lstlisting}

\begin{lstlisting}[language=bash,caption={本文档编译}]
cd docs/latex
make          # xelatex ×2
# 产物：build/main.pdf
\end{lstlisting}
