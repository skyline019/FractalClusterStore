\section{评估与对标}
\label{sec:eval}

\subsection{正确性}
\begin{itemize}[leftmargin=1.6em]
  \item Strict CI：Compile（\texttt{-Werror}）$\to$ Smoke $\to$ Full test $\to$ Sanitizers $\to$ \textbf{Strict CI OK}。
  \item \texttt{make test}：含 f/g/h/s/c/r/b；R17/R18 增量 \texttt{g15}--\texttt{g18}；CRC/P2 \texttt{c2}--\texttt{c6}。
  \item 掉电：\texttt{g6}/\texttt{h3}；模糊：\texttt{h1}/\texttt{g5}。
  \item 消毒：\texttt{make asan}（ASan/UBSan + TSan 子集 w1/g7/g11/g13/g14/g17）；WSL TSan 用 \texttt{setarch -R}（坑 122）。
\end{itemize}
缺口：无小时级 soak 标真拔电；无多进程文件锁；默认 \texttt{get} 不查数据 CRC。

\subsection{延迟}
\begin{itemize}[leftmargin=1.6em]
  \item 提交 fsync 出锁：慢盘探针数量级收益；本机快 fsync 上收益有限。
  \item 读者 max 残余常来自维护单元（预算内），而非提交 sync。
  \item 多写者：\texttt{ml\_mu\_} 串行提交后维护（坑 153）；吞吐加速仍有限（\texttt{flush\_mem}）。
\end{itemize}
